HCRM architecture

Hierarchical Channel-Routed Memory. This run’s encoder is the L40S 500M model in hcrm/model.py and hcrm/routing.py. There is no global self-attention. Sequence mixing is O(T) local convolution; long-range / topical memory is a bank of 512 channel FFN rows selected by a 1-D locality-sensitive router.
Design invariant
Nearby semantics should land on nearby channel rows. A learned scalar routing index u in (0, 1) is compared to equally spaced bucket centers with an RBF (sigma = 0.08). Channelites are coarse ranges; channels are fine rows inside those ranges. Discrete routing uses temperature tau (train anneal 1.2 to 0.3, infer 0.1). Train is dense softmax over all 512 channels; infer is top-8.

One HCRM block

Residual scale is 0.5 on both branches so an untrained residual does not explode. Mix is the only left-to-right sequence operator. Channels are position-wise (no token-token attention).

Causal local mix (replaces attention)

Eight stacked mix layers still only cover a local window of tens of tokens, not the full 2048. Anything farther must be stored in the channel bank or the external runtime table — that is the point of HCRM versus a Transformer.
Mix params per layer: conv 4,096 + gate 262,656 + out 262,656 = 529,408. Eight layers: 4,235,264.

Hierarchical router

Per token, Linear(d→1) produces u = sigmoid(key(x)) in (0, 1). That scalar is scored against channel and channelite centers with RBF logits. Parent channelite mass is log-added so a token cannot easily jump outside its coarse range. Train uses dense softmax; infer uses top-8.
Train gates = softmax((RBF_ch + refine(x) + log(parent)) / tau). Router params: 296,001.

Channel bank (the memory matrices)

Independent SiLU FFNs packed as W1[c,d,f], W2[c,f,d]. Output is sum_c gates[b,t,c] · FFN_c(h[b,t]). Bank is shared across all 8 layers — one memory, eight reads. This is where almost all 500M parameters live.
Unique count skips the tied LM head (same storage as embed). Channel bank 470,482,944 + embed 25,165,824 + mix 4,235,264 + router 296,001 + norms 8,704 = 500,188,737.

What is not in the weights

At chat time the encoder is frozen. New facts go to runtime/table.jsonl. Retrieval score is 0.50 cosine + 0.20 RBF(u) + 0.15 recency (12h half-life) + 0.15 keyword overlap. Run /forget after switching checkpoints.
